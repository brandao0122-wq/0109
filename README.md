## Comando em linha e bloco de codigo

o comando ` git status ` mostra o estado atual do repositorio 
o comando ` git add ` adiciona todos os arquivos modificados a *staging area* 

o comando ` git commit -m "texto commit" ` registra as alteração como uma mensagem 

```bash

git add 
git commit -m "testo commit"
git push -u origin main 

```
